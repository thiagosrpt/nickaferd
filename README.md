# Nickaferd Video Portfolio (Next.js + Tailwind)

Minimal static portfolio site scaffold using Next.js and Tailwind CSS.

Getting started

1. Install dependencies

```bash
npm install
```

2. Run development server

```bash
npm run dev
```

3. Build and export a static site

```bash
npm run export
# output will be in the `out/` folder
```

Notes
- Edit video entries in `data/videos.js` to list your YouTube/TikTok videos.
- This scaffold uses the Classic Pages router so it can be exported with `next export`.
